这是一轮明确标明采样范围的视觉检查，未声称人工观看了全部逐帧序列。

## 原有 20 人

样本中头、衣物和肢体均在画布内，没有观察到头颅、手臂或腿成为悬空整块。四方向与其他动作仍属于栅格分区骨骼变形，衣物边缘会有细微形变；同一动作保持同一关键源姿态。脚步/手臂存在独立变化，不是整张人物上下漂动。

旧透明化流程留下的白色衣服/白鞋/厨师帽缺色仍明显可见，例如男主白T与白鞋、医生白衣、厨师帽；淡色场景可见轮廓，深色场景会透出底色。该问题来自只读原图，新增动画未修补原作颜色。切换不同动作时，原始 AI 关键姿态脸型和比例差异可能仍出现，应作为原资产局限记录。

## 动物：修订后复核

已重新生成四页宠物采样图，并再次查看所有 20 只动物。主代理将裁切图层改为连续逆向骨骼变形，飞行翅根定位到实际不透明肩部。本次修订版复核结果：

| 上轮问题 | 修订后结果 |
|---|---|
| 12 绿虎皮、13 蓝虎皮、14 玄凤飞行翅膀悬空 | 四相位中的翼面与肩部相连，未看到悬空三角块；羽色跟随各鸟体色 |
| 03 蓝猫清洁时胸前透明裂缝 | 第 0、4、8、12 帧未看到横向裂缝，头胸保持连接 |

| 虎斑/三花尾尖脱离小块 | 所查看相位尾尖与尾干相连 |
| 鸟爪、马驹腿等显著分离轮廓 | 全部宠物动作的 64 px 轮廓自动扫描未再发现面积至少 3 个逻辑像素的多个显著断开部分 |

宠物采样中没有发现头、腿、翅膀被画布裁切的情况。05 缅因已替换为自然四足站姿源图并重新生成全部动作，查看 `production/maine-standing-check.png` 确认脚与躯干相连、透明背景无明显光边。仍应如实保留当前制作方法的局限：16 垂耳兔、17 荷兰兔的原素材为蹲姿，步行是现有姿态的短步/跳步近似；飞行翼面较简化，鸟类上下方向共享侧视移动，进食/饮水以头部轻倾表示，休息以伏低近似而非独立绘制睡姿。清洁是头部和前爪的局部运动，不是完整抬爪舔毛序列。不能将程序化动作描述为每个物种专门手绘的完整自然行为动画。

男女各 10 人，覆盖消防、杂货、农业、驾驶、理发、烘焙、图书、维修、旅店、花艺、咖啡、木工、邮政、警务、医疗等日常岗位。正面脸型、年龄感、眉眼、鼻口、发型和体型分别设计，身份配对页可见长脸、方脸、圆脸与不同五官组合；同职业提供不同形象。

步行和挥手采样未见完整头部、手臂或腿部脱离躯干。方向图含独立背面关键图；左右视图通过镜像配套。脸和关键动作来自生成图，补帧使用像素区域骨骼，局部五官、衣物和工具仍可能在动作切换时出现差异。工作动作用工具及局部运动提示职业，不包含完整驾驶、灭火或诊疗交互。未声称已逐帧精修全部动作。

## Codexmini

基本动作板未看到新增导入造成的人体裁切、断肢或漂浮头部。预览保留原始节奏及动作，manifest 的 `durations` 数组是实际时间依据。一些单次动作在 GIF 预览中无限循环而 manifest 标为单次，此差异由统一工具记录提示，游戏应执行 manifest。原作没有背面/正面走路、睡眠、进食等动作，`missingActions` 已明确列出，不能补称已经具备。

## 当前总体结论

统一检查覆盖 65 个对象，全部通过文件与动画技术检查；共 758 组动作、0 个错误、86 个提示。提示主要涉及保留原作透明边缘、GIF 连续重复帧合并、单次动作预览循环。动物上一轮结构性视觉问题已在修订版采样复核中消除；原有和新增人物的采样已查看，动作语义和源姿态局限仍保留上文说明。

游戏已读取 PNG 图集与实际逐帧时间，支持选择背景预设、邀请自然动物与 Codexmini、按物种限制 API 行为。包内资源的真实界面检查通过人物与动物选择、图片解码、邀请、未入住动物档案编辑、动画推进和暂停冻结；使用内存存档，真实 API 调用为 0。当前项目自动测试共 52 项通过，其中也包括并行开发的玩家外观测试。技术与界面通过不等于物理步态或最终美术质量验收。
