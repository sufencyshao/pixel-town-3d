# 小镇人物与自然动物素材使用说明

本批目录围绕小镇的日常运行组织：原有 20 位人物、新增 20 位人物、20 个自然动物个体，以及 5 位从本机原包邀请加入的 Codexmini 伙伴。原人物与新增人物分别为 10 男 10 女；自然动物不以人类性别或职业配额设计。Codexmini 保留原有 Q 版人形或幻想形象，属于剧情身份，不能与真实猫狗鸟的生物行为设定混用。

## 浏览与目录

双击打开 [asset-gallery.html](asset-gallery.html)。页面为中文离线画廊，数据已嵌入 HTML，不依赖本地 `fetch`、服务器或网络字体。默认只加载静态透明 PNG；打开对象档案、选择动作后点击播放，才加载该动作 GIF。支持原有居民、新增居民、自然动物、Codexmini 分组，以及名字、职业、品种搜索和物种筛选。详情中可切换背景预设、查看作息、打开完整 Markdown 档案和动画清单。

```
pixel_town_assets/
  asset-gallery.html
  expansion-guide.md
  characters/
    01_hero_male/ … 20_student_female/     原有居民
    21_…/ … 40_…/                        新增居民
  pets/
    01_…/ … 20_…/                        自然动物
  codexmini/
    hai-qin-yan/  xin/  xin-fragrance/
    kanna/  rui/
  tools/                                  生成和验证工具
  validation/                             技术检查及视觉记录
```

每位人物与动物有独立文件夹：`profile.md` 是可读档案，`profile.json` 是可供程序读取的身份和可选预设；基础 PNG 展示站姿或动作关键姿势，`animations/` 中放逐动作透明 GIF 与横向 PNG 图集，`animation.json` 定义帧尺寸、动作时间与锚点，`overview.gif` 依次展示各动作。Codexmini 另有 `portrait.png`、`basic_actions.png`、`frames/` 逐帧图片与 `source/` 原图集。

画廊按实际存在的文件生成，不会把只有预设文件、缺少图片或动画的目录显示成完整美术。制作中的缺图目录会明确显示“素材准备中”。最终完整性以最新统一验证报告与实际文件为准。生成新素材或修改档案后，运行以下命令刷新离线画廊：

```sh
python3 pixel_town_assets/tools/build_gallery.py
```

## 人物：形象、职业与预设

原有 20 位人物每位提供 3 套可选背景，共 60 套；分别写明职业、性格、成长或搬迁背景、兴趣、交流风格、主要地点、职业事务和具体作息。新增 20 位人物也各有 3 套可选预设，补充小镇岗位并提供同一职业的不同形象。设定属于虚构设计，不能由外观推断现实人物身份。切换预设应同步角色职业与行为倾向；游戏实例已有的私人记忆不应被其他实例的资料替换。

人物连续动作包括待机、四方向行走、挥手、惊讶、坐姿、跳跃、欢呼与工作，通常每动作 16 帧，80 ms/帧，单周期 1.28 s。基于现有栅格关键姿势，按头、躯干、手臂、腿部等空间区域分别运动，用周期步态、呼吸、重心位移和动作轨迹形成连续循环。工作工具与具体幅度按角色职业设置，表现一般职业活动。

这些动作是**程序骨骼分区近似扩展**，不是逐帧手工精修。源姿态和分区边界可能留下衣物形变；握持、工具遮挡、脚部接触、精细碰撞和完整岗位操作仍需更细的动画与状态设计。源图不同姿态的脸型、服装或头身差异在切换动作时仍可能可见。工作循环不代表完成了一次真实操作，任务结果仍由游戏逻辑决定。

`overview.gif` 中不同动作之间采用展示切换，不能把这一切换宣称为站到坐、惊讶到恢复等已制作的跨动作自然转场。更详细的原人物制作与验证说明见 [existing-animation-production.md](tools/existing-animation-production.md)。

## 自然动物：按物种行动

20 个自然动物个体通过物种、品种、花色、体型和行为倾向区分，包括猫、狗、鸟、兔与龟等。每个 `profile.json` 的 `animal` 字段记录感官视点、栖息环境、移动方式、形象比例、速度与动作白名单。猫狗以四足移动，鸟类以双足栖停或跳步和双翼飞行，龟表现缓慢四足运动；各动物按自己的体型占用空间。

动物不赋予人类职业、语言、服装、工具操作或人类心理动机。视觉、气味、声响、附近动静、食物、饮水、安全位置与退路可以触发自然观察、嗅闻、进食、梳理、休息或避让；预设的“谨慎”“活跃”等仅描述接近、活动与应激倾向。物种视角是游戏里的感官近似，不等同于模拟动物意识。

动物可独立绑定 API，模型只在物种动作白名单内输出结构化意图。应用层继续约束体型、比例、运动方式和可达位置；未识别动作或格式错误应回退本地规则。人类对话不能直接当作动物能理解的人类语言。完整行为和禁止项已写入各动物档案。

动物动画同样采用程序化区域运动与物种骨架近似。飞行、关节接触和毛羽遮挡需要逐帧视觉评估，不能只凭文件帧数宣称生物力学自然度已达最终质量。

## 5 位 Codexmini：保留原创身份

导入本机当前安装的海琴烟、歆、馨、康娜、锐；旧版备份不重复加入。每个原包为 V2、8 列 × 11 行图集，单元 192 × 208 px。导入时只提取真实姿势并透明补边到 256 × 256 px，偏移 `(32,22)`；不缩放变形、不生成伪造帧、不覆盖源包。原文件复制到各自 `source/`，路径与 SHA-256 在 [import_manifest.json](codexmini/import_manifest.json) 中。

每位包含 10 类动作、73 个真实原始姿势帧，保留原行节奏。`running-right` / `running-left` 对应左右移动；原状态 `running` 是任务进行，映射为 `work`，可能包括电脑或海琴烟弹竖琴等原设计姿势；`look` 是连续转向观察，不是步行动画。当前原包没有上下方向行走、进食、睡眠专门动作，档案与动画清单均明确列为缺失，不用观察姿势冒充完整步态。

每位提供 3 套可选剧情背景，保留原形象和伙伴身份，不强制安排人类工作。源元数据未明示性别，暂标为未指定。它们的 Q 版人形与幻想身份不用于定义真实动物的行为。

## 游戏播放与性能

本次已接入 `pixel-town-app/`：设置中的居民名单包含 40 位人物与 5 位 Codexmini；“动物与宠物”中可邀请 20 只自然动物、选择气质预设并绑定独立 API。原有居民名称和已编辑实例记忆、模型与人设在旧存档迁移时保留。默认仍有 6 位居民入住，其余由玩家选择邀请。

游戏实际加载 RGBA PNG 图集，根据 `animation.json` 在横向单行图集中裁切 256 × 256 单元，并随暂停和游戏速度改变播放。GIF 用作可独立查看的预览；GIF 的单色透明和有限调色板不替代 PNG 的完整 Alpha 与颜色。应用只复制运行需要的 PNG、清单和档案，不复制全部 GIF 与原始生成文件。

- 固定时间动作：按 `floor(elapsedMs / frameMs)` 找当前帧；循环动作对 `frames` 取余。
- Codexmini 变时长动作：累加 `durations` 找当前帧；动作周期是所有时长之和，不能把第一帧 `frameMs` 当作全部帧时间。
- `loop: false` 的动作由状态机播放一次后切回待机；独立预览 GIF 为便于观察可循环展示。
- 位置移动由游戏坐标推进；行走图集表现原地步态，不包含完整地图路径。
- 按需要缓存角色和当前动作，避免一次解码全部图集。16 帧横向 RGBA 图集约 4 MiB，批量预览 GIF 也应按需加载。
- 以锚点定位脚部，结合 `animal.scale` 和各角色体型信息设置世界比例与碰撞范围。切换贴图时保持世界坐标和脚部锚点一致。

接入 API 时，“模型选型”“居民实例记忆”“角色形象”“预设背景”和“可执行动作”是各自独立的信息：预设提供扮演边界，动画清单约束可播放动作，行为系统决定事务与位置。角色只知道自己的观察、亲历、公开公告与交流内容，不读取其他角色的私有记忆。真实医疗相关角色仅作游戏内一般交流，不能据剧情给玩家真实诊断。

## 验证与自然度边界

技术验证覆盖文件与清单、帧尺寸、透明通道、GIF实际帧数及总时长、空帧与裁切提示、源文件校验等。统一检查可运行：

```sh
python3 pixel_town_assets/tools/validate_assets.py
```

查看 `validation/asset-validation.json`、`validation/asset-validation.md` 和对应视觉记录；既有人物动作另有 `tools/existing-animation-validation.json`，桌宠来源与真实帧检查另有 `codexmini/validation.json`。`ready` 表示技术格式满足检查，不能代替逐帧动作语义与视觉自然度验收。GIF可合并连续重复帧时，仍须验证总时长，并在报告中如实列出。

2026-10-02 本次交付：65 个对象、758 组动作，文件技术错误 0、提示 86；人物 40、自然动物 20、Codexmini 5。人物各 3 套背景，动物各 2 套气质，Codexmini 各 3 套剧情背景。已查看人物、动物与 Codexmini 的动作采样及新增人物正面/挥手身份配对，范围和局限记录在 `validation/visual-review.md`。原有 PNG 的白衣/白鞋透明缺色没有覆盖修改；骨骼补帧、兔子跳步、鸟类翅面及清洁动作仍是近似表现。

当前项目自动测试 52 项通过（包含并行开发的玩家功能）；对构建包中实际界面与资源的检查通过 45 个人物/伙伴和 20 只动物的图片加载、邀请、预设编辑、动作播放与暂停，真实 API 调用为 0。独立包路径为 `../pixel-town-app/dist-mac/像素小镇.app`，本机临时签名已通过校验。真实服务商连通性仍按用户自己的 API 配置测试。

交付包应整体保留目录关系。单独发送 `asset-gallery.html` 会丢失相对链接的 PNG、GIF 和档案；携带完整 `pixel_town_assets/` 后，画廊可离线打开。
