# 归档范围与事实边界

本次按现有文件建立首次 Git 历史，不伪造此前逐日提交。制作历程由 `PROJECT_CONTEXT.md`、分主题制作记录、原版本说明、源脚本和各成品档案共同记录。

- 应用源码、构建脚本、人物公开设定、二维运行素材和设计源代码直接进入 Git。
- 体积较大的模型、Blender 工程、嵌入资源的离线预览、二维原始导出和应用包进入 Releases，文件清单、SHA-256 与分类下载目录进入 Git。
- 现有 30 个设计 ZIP 按建筑、整镇、写实模型、历史美术分组；二维制作素材另打完整档案包。
- 原 AI Chat 应用、node_modules、Electron 缓存、应用安装副本、个人 API 密钥、私人存档/日志、完整聊天和本机私有数据校验清单不在归档范围。
- 旧 V6 自建动物、旧自建人物与 Quaternius 卡通试验仅为历史过程，用户已否定或已被后续要求取代，不视为当前采用或用户认可。

- 原件许可证随包保留；未统一改为 MIT，不因为项目不营利而改变第三方权利。
