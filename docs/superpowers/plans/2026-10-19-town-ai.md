# 三维小镇 API 与角色操作

本轮采用 writing-plans / executing-plans 的文件计划与逐项验证方法，按用户已经授权的完善请求直接实施。

## 设计边界

- V8 作者原版模型、旧二维应用和存档结构保留；新增 V9 三维入口，复用主进程服务商密钥与角色绑定。
- 模型资料来自当前 catalog 与存档，按 catalogId 映射三维身份。仅当前预设生效，关系未知就是未知。其他居民的公开档案与自己的记忆分开。
- 主进程组装三维能力文档、校验 JSON 计划；渲染器执行原动作、限幅骨架姿态、公共步道寻路及分阶段职业练习，实际回执送回下一次上下文。
- 未附步行动画的动物不滑动冒充行走；无室内导航、工具抓取/IK、实物生产或货币系统的能力如实注明。
- 自主调用默认关闭，单次/自动均受预算限制。关闭、手动干预、配置变化使过期请求失效。密钥不进入页面上下文、模型档案或三维文件。

## 实施

1. `shared/town-3d-protocol.js`：动作协议、关节限制、严格解析；`design/town-ai-v9/capabilities.json`：从原 GLB 骨骼/动作及职业元数据生成可信清单。
2. `main/town-3d-context.js`、`main/town-3d-service.js`：真实身份/背景/关系/作息、三维世界说明、请求/取消/预算/原子回执存储。
3. `main/main.js`、独立 `main/town-3d-preload.js`：限定窗口 IPC、三维入口和既有 API 设置接入。
4. `design/town-ai-v9/src/`：复用 V8 景观，新增公共步道导航、动作序列/姿态恢复/工作阶段/交互 UI；独立打包 HTML，不覆盖 V8。
5. `scripts/town-3d-*.test.js`：协议、档案、失效请求、预算和写入失败；本地 HTTP/SSE 模拟服务商及实际 WebGL 角色位移、骨骼、职业阶段和密钥隔离检查。
6. 更新 V9 使用说明、验收记录与 `PROJECT_CONTEXT.md`，打开可操作入口。

## 验证

无需真实付费 API。隔离数据目录 + 本地模拟服务商；不读取或写出真实密钥；正式数据只做文件摘要核对。保留失败证据并修复后重测相关项目。
