## 文件

- `assets/01-Ache.blend`：Blender 5.2.2原生工程，包含打包纹理、人物、衣服、鞋子、骨架及动作。
- `assets/01-Ache.glb`：供Three.js等引擎导入的完整模型、骨骼、动作及表情目标。
- `assets/manifest.json`：身份、动作及表情索引。
- `src/`、`template.html`：制作、导出、验证及离线预览打包源文件。
- `reference/`：冻结的C样例、原2D参考、动作库、GitHub取得的休闲/工装角色、来源摘要及许可证。
- `qa/`：原生模型检查、浏览器检查、原文件保护摘要和实际截图。
- `人物复用与体型规范.md`：逐人体型与成熟模型复用要求。其他居民尚未批量制作。

## 已实现

阿澈保留原2D参考的黑短发、棕眼、黑上衣、蓝裤辨识点。使用C基础的65骨骼（含辅助/末端骨，并非65个解剖关节），分离上衣、裤子与鞋子。肩部服装沿身体原拓扑与权重制作，补圆领和腰带细节。

鞋子采用Quaternius Modular Men中Casual角色已有的鞋网格，保留其鞋头、鞋跟、鞋面和鞋底形状，改为浅色休闲配色，重新适配阿澈脚部，并补充鞋带。该源角色本身来自固定GitHub提交，详见`reference/modular-men-source.json`。

共有19个动作片段：

| 类型 | 动作 |
| --- | --- |
| 交流与移动 | 站立、走路、慢跑、挥手、交谈、点头、摇头 |
| 坐蹲与作业 | 下蹲、蹲行、坐下、坐着、起身、桌面拾物、跪姿作业 |
| 活动 | 舞蹈、游泳动作、起跳、空中姿态、落地 |

支持播放/暂停、0.5/1/1.5倍速、拖动进度、旋转缩放、五个观察位置、骨骼开关与GLB下载。坐下后自动转为坐着，起身后转为站立；其余单次动作也有简单后继。椅子和水面是预览中的接触示意，不包含在人物GLB里。

`Blink`、`Smile`、`Talk`为模型内的表情目标；自动眨眼和简化张口由预览脚本驱动。导入其他引擎时需自行驱动表情，并非音频口型同步。

## 验证与限制

66项Blender保存重开/GLB重导入检查、51项浏览器检查通过，包含19动作切换、表情、坐起过渡、模型下载摘要、1440px与390px布局、断网file打开及控制台检查。原A/B/C样例的53个文件和原2D参考摘要保持不变。具体证据见`验收报告.md`与`qa/`。

V1.1另外增加13项挥手专项检查，原生与GLB各采样73个姿态，覆盖肘部屈曲方向、手掌朝向、关节连接、循环连续及导出一致性。网格数据与另外18个动作的关键帧摘要保持不变。

本版仍是美术和动作首版。体型、眉眼气质、领口/衣摆/裤脚的细部与动作接触还可继续修整；没有衣物物理、完整碰撞、脚底IK、家具高度适配或工具握持。作业为空手示意，拾物没有真实物品，游泳没有水体交互。吃饭、喝水、侧躺等完整生活动作尚未制作。

当前只有阿澈。C是整体风格参考，其他人物将分别选择底模、调整身高和各部位比例，并逐人核对原2D辨识点。本版没有修改正式应用、人物API、存档、原2D资产或整镇V5。

## 来源与复现

人物和动作基础：Quaternius Universal Base Characters、Universal Animation Library 1；成品鞋：Ultimate Modular Men / Casual。来源版本与许可证随包保留，详见`THIRD_PARTY_LICENSES.txt`、`reference/upstream-source-manifest.json`和`reference/modular-men-source.json`。Three.js使用MIT许可。没有采用下载仓库内的游戏代码。

使用Blender 5.2.2运行`src/build_character.py`，然后运行`src/verify_character.py`。首次重新提取成品鞋可运行`src/extract_casual_shoes.py`，已有派生网格JSON随包提供。网页依赖版本记录在`package.json`，安装后运行`npm run build:viewer`和`python3 src/package_preview.py`。浏览器验收需已安装的Chrome及Playwright，运行`npm run verify:browser`；`PREVIEW_URL`可覆盖默认本地预览地址。HTML成品本身不需要上述开发依赖。
