# 共享人物动作库 · C自然比例居民 V2

2026-10-18。制作范围仅为本 motion 目录；这是 45 位居民重定向的共享动作源，逐人比例、衣服穿叠、脚底与家具接触由居民装配阶段验收。

`shared-motion.blend` 内只有 `ResidentMotionRig` 一件对象、65 个标准骨骼及 30 个完整 Actions。`qa/actor-motion.blend` 是单独的阿澈参考演员，用于检查动作，不能当作本轮新居民或最终体型。

## 文件与接入契约

- `actions.json`：中文标签、实际帧数/时长、循环或单次、来源、道具挂点及侧躺动作链。
- `bone-rest.json`：65 骨骼名称、父级、rest head/tail/matrix、单位与对象矩阵。
- `contact-samples.json`：每项动作起/中/止的骨盆、头、手、腿、脚关节位置，以及参考网格地面最低高度。
- `sources.json`、`licenses/`：冻结的 Quaternius 来源、许可和动作边界。
- `qa/validation.json`、`qa/wave-axes.json`：逐帧数值与 Wave 解剖屈曲轴验证。
- `qa/daily-contact.png`、`qa/lying-wave-contact.png`：9 项动作 × 4 阶段 × 正/侧两视角，72 张实际骨骼变形图的联系表。

标准空间为 Blender **X右、-Y前、Z上**，数值为骨架局部米。原 rig 的对象缩放为 **0.896874785**，需保留，或在导出时只烘焙一次；不能再次套用该系数。把同名骨骼的 basis 四元数传递到比例调整后的同源 rest 骨架，骨盆位移按目标比例换算。`pelvis.location` 是骨骼 pose-local 通道，不是直接的世界 Z。

**重定向逐帧烘焙时先 normalize 四元数。** 原 22 项动作曲线完整保留，源曲线插值的原始模长误差最高 0.00157；保留曲线与记录该误差，避免悄悄改写原动作。新增 8 项在每个整数帧归一化并统一相邻四元数半球，不能出现 q/-q 线性插值穿零。

手骨的 **+Y 沿手指、+X 是掌面法线、+Z 横跨手掌**。道具挂点的 position 与 WXYZ 四元数均在手骨局部空间。碗、书、手机有相应旋转，不可按“+Z就是掌面”直接挂。清单使用常规道具 +Z 方向描述；手机屏幕特意为 -Z 朝向读者。挂点是动作接入契约，个体手掌/手臂比例仍需实物握持微调。

## 动作范围

原 C1.1 的 19 动作完整复用，Wave 保留已经修正的肩部 roll、前臂单轴屈曲与正向掌面。V6 的 Pet、Feed、ThrowBall 三项保留；Pet/Feed 是源版本的稳定跪姿片段。

新增 8 项为本次原创骨骼动作：

| 动作 | 时长 | 播放 | 内容 |
| --- | --- | --- | --- |
| Eat | 4.0 s | 循环 | 左手端碗，右手把匙送至嘴边并返回 |
| Drink | 3.8 s | 单次 | 右手抬杯、倾杯饮用、放低 |
| Read | 4.0 s | 循环 | 双手承书，低头，细小视线/呼吸变化 |
| Phone | 4.0 s | 循环 | 左手持机，右手食指重复小幅点击 |
| Stretch | 5.0 s | 单次 | 从站立抬双臂过头，轻微伸展后放下 |
| LieDown | 5.0 s | 单次 | 站立→下蹲→低坐→侧躺 |
| LieRest | 4.0 s | 循环 | 横卧躯干、双膝弯曲、右前臂和手掌托头、左手放腹部 |
| GetUp | 5.0 s | 单次 | 与躺下相反的侧卧→低坐→下蹲→站立过渡 |

已检查原 UAL1 的全部 43 个片段，包含移动、坐蹲、舞蹈、游泳、作业和战斗。没有适合吃饭/看书/手机/侧躺的现成片段，因此没有把其他片段改名当成这些动作。阅读/手机/吃饭的道具不在共享骨架文件里；参考图的简单实物仅用于验证挂点。

## 重建

使用项目当前 Steam Blender 5.2.2 执行：

```sh
Blender -b --python build_motion.py
Blender -b --python validate_motion.py
Blender -b --python render_qa.py
python3 contact_sheet.py
```

脚本会读取本项目原 C1.1 与 V6 冻结演员源，仅写入 motion 目录。联系表脚本使用 Pillow。
