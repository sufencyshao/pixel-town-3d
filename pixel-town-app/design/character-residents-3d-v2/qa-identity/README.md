# 独立人物外观 QA

本目录只读原2D、身份参数和制作端资产，不改写它们。所有渲染、诊断及对照页只写到本目录。

## 入口

- `render_identity_review.py`：原生Blender及重导入GLB的自然光工作室渲染。默认小满11张，`--ids ID1,ID2`指定批次，`--all`取身份表全45位，`--static-only`只出正/前侧/侧/脸部4张，`--glb`改为GLB重导入。
- `compose_review.py`：从已有PNG生成每位原图/动作对照图，以及每15人一页的全员原2D/3D对照。
- `audit_shape_keys.py`：只读检查所有已制作.blend中Basis与网格的一致性、默认表情归零、局部表情位移范围。
- `首个试制QA.md`：首份小满的阻断问题，失败证据冻结在`02_hero_female/prototype-01-failed/`。

## 状态边界

身份审计与模型视觉验收分开。原始试制存在已报告的表情Basis和上衣UV问题，等待制作端重建后复检。当前图片不能作为45位模型通过证据。

裙装的0边界边证明布壳闭合；它不能证明坐姿和行走时无皮肤穿透。动作自然度需要逐张前/侧图核对，不能由几何与文件格式检查替代。

原生文件与GLB在渲染前后记录SHA-256，未保存修改后的输入；渲染场景的灯光、相机、地面仅存在于进程内存中。
