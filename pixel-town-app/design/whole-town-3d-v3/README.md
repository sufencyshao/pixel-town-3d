# 溪畔日常 · 昼夜与天气 V3

打开 `完整小镇-离线预览.html` 即可离线体验。以完整小镇 V2 为基础，新增实时昼夜、模拟时间、自动路灯和七种天气；保留九区、楼层剖切与街景近看功能。

## 操作

- 时间默认从第 1 天 08:00 开始，一天约 24 分钟。可切换实时、24 分钟/天、6 分钟/天、1 分钟/天。
- 点击清晨、正午、傍晚、夜晚，拖动时间条或输入时分，立即定位并暂停时间。点击「继续时间」恢复；跨过午夜后天数增加。
- 时间暂停时云、雨、天气过渡继续播放。页面切入后台时暂停推进，返回后从离开时继续。
- 53 盏路灯随日落渐亮、日出渐灭；有灯罩发光、暖光晕和地面光斑，焦点附近八盏灯使用实际点光源。
- 晴天、多云、阴天、小雨、中雨、大雨、雷暴可直接切换。云量、日照、薄雾、雨量和风势平滑过渡；铺装逐渐湿润，雨停后缓慢变干。
- 自动天气默认关闭，开启后按小镇时间每三小时轮换，手动选天气会退出自动轮换。
- 雷暴包含周期闪电和「预览闪电」。闪电可关闭；系统偏好减少动态效果时默认关闭。雷声独立开关，默认关闭，须点击后才启用浏览器音频。
- 展开「查看区块、街景与建筑」可选择九区、俯视、剖切、楼层和街道近景。剖切模式隐藏雨幕便于查看室内；隐藏街道设施时同步隐藏路灯光效。
- 「保存画面」导出当前三维画面；「下载 GLB」导出静态整镇模型。

## 文件

- `完整小镇-离线预览.html`：已内嵌模型、脚本和环境采样，无需联网或安装依赖；约 115 MiB。
- `Town-complete.blend` / `Town-complete.glb`：原 V2 静态整镇模型，字节一致。动态昼夜和天气由本预览中的 JavaScript 运行，不包含在 Blender / GLB 文件中。
- `src/environment-state.js`：模拟时钟、太阳高度、天气状态与渐变。
- `src/environment-renderer.js`：天空、照明、雨幕、涟漪、湿地、闪电及合成雷声。
- `src/viewer.js` / `template.html`：整镇浏览器与交互面板。
- `environment-data.json`：53 盏路灯坐标和 11,011 个地表/屋顶高度采样。
- `src/export_environment.py`：从随包 Blender 文件重新提取环境数据。
- `qa/`：本次验收数据与截图；详见 `验收报告.md`。
- `整镇分区总图.svg / .png`：V2 的静态标注总图，供区块定位使用。

## 重建

已生成的 HTML 可直接打开。修改源码时在本目录执行：

```sh
npm install
npm test
npm run preview:build
```

模型变化后另执行 `blender -b --python src/export_environment.py`，再重建预览。依赖版本为 Three.js 0.180.0、esbuild 0.25.9，许可证见 `THIRD_PARTY_LICENSES.txt`。

## 当前范围

这是整镇交互设计预览，尚未接入像素小镇正式应用、人物生活、交通、碰撞、寻路、API 或存档。重新打开预览从默认时间/天气开始。

雨的遮挡来自 2.5 m 网格的最高表面采样，檐边和细小缝隙处为近似；涟漪为风格化表面效果。地面湿润使用颜色与粗糙度变化，没有积水水文或真实倒影。八盏局部点光源随视角焦点选取，其余路灯用暖色光斑表现；未计算每盏路灯的独立阴影。雷声为程序合成，未联网取音效。

整镇仍有约 145 万三角形，适合桌面浏览；已验收 390 px 手机视口布局，但真实手机性能取决于 GPU，未进行真机验收。
