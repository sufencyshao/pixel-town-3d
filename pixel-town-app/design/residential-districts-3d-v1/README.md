- `AC-residential-districts.blend`：原生工程，5个已保存的取景场景，含完整楼层及分组。
- `AC-residential-districts.glb`：A/C及邻接道路上下文整体模型；米制、Y向上。
- `住宅区落位.svg`：标注楼栋的矢量平面图。
- `A-overview.png`、`C-overview.png`、`A-plan.png`、`C-plan.png`、`AC-placement.png`：渲染图。
- `manifest.json`：各栋位置、户数、源文件SHA-256、步道与地块边界。
- `validation.json`、`qa/browser-checks.json`、`验收报告.md`：本轮检查。

## 装配说明

A、C 区中心沿原总图东西方向相距165.625 m。为保留这个关系，总览展示中间B区占地和邻接道路；B区建筑、其余分区及河流尚未装配进本文件。

A区两列别墅位于x=±24.5、y=20/0/-20 m，主角家位于(0,-16)m。C区两列从原建议的±13调整至±13.625 m，中央留出2.25 m步道。所有住宅缩放1、旋转0，南向入口连接连续社区路网。

为减轻装配场景开销，住宅各楼层墙面、地板、家具、楼梯、屋顶和景观分别合并为网格；源面数、材质及几何尺寸保留，重复楼栋共享网格。五种原始住宅 `.blend`、GLB 哈希均未改变。

本轮交付为静态设计落位。人物入住、游泳、碰撞和寻路未接入运行应用。

## 复建

依赖相邻 `../residential-3d-v1/` 五种源住宅工程。使用 Blender 5.2.2 LTS 执行 `src/build_districts.py`；`AC_SKIP_RENDERS=1` 可跳过渲染。之后 `npm ci && npm run preview:build` 生成内嵌资源的离线HTML，`python3 src/make_plan.py` 生成SVG。独立压缩包包含成品；需要复建时另需住宅源工程。
