# 溪畔住居 · 住宅模型 V1

2026-10-13。按本轮要求制作庭院双层花园别墅、带小泳池的主角双层别墅，以及每层两套的3、4、5层河畔公寓。沿用米白墙、自然木色、绿色庭院的小镇风格。

## 空间安排

庭院别墅与主角家：一层为客厅、餐厨、书桌和卫浴，西侧楼梯通往二层；二层为主卧、客卧兼书房、卫浴、阳台。层高3.25 m，真实楼梯与楼板开口。庭院含草地、绿篱、露台、种植与廊架。主角家增加泳池、池边铺地及躺椅，池体有独立底板/侧壁及水面，水深模型参数约1.33 m。按本轮追加反馈，后院新增3块约2 × 3.4 m的小菜畦（青菜、香草、番茄），前院入户道路两侧各设自然绿化花园，以草坪、灌木、观赏草和白、粉、黄、紫色花卉错落组合，不设方形种植边框或整齐行列；绿篱入口与入户路对齐，菜畦之间留步行间隔。

河畔公寓：主体22 × 11 m、模型场地约25 × 17 m，层高3.2 m。“一栋楼两个单元”按用户明确的“每层两个套房”实现：每层左右各一套独立住宅，共用中央入口、门厅与双跑楼梯。每套含一间卧室、客餐厅、厨房、独立卫浴、书桌和阳台。并非两个楼梯单元各两户的四户布局。

已核对`pixel_town_assets/roster.json`：40位human角色、5位codexmini伙伴；运行素材目录也分别有40份和5份profile.json。20只自然动物不作为独立住宅住户，主角另计。此处是按现有角色库进行容量设计，不是读取或修改正式存档的当前入住人数。

沿用原总图6栋庭院住宅位置数量，但按本轮“小别墅”改为每栋独立1户。五栋河畔公寓采用3、4、4、4、5层，每层2套，合计40套。总计46户居民住宅，若40位居民与5位伙伴均独立入住，剩余1户；主角另设1户。不强制五位伙伴入住，也没有把某个角色永久绑定到某户。

- A01–A06：各一栋庭院别墅；A07：主角泳池别墅。
- C01：3层6套；C02、C03、C04：各4层8套；C05：5层10套。
- `housing-capacity.json`列出46个稳定住宅ID和空的residentId，供之后分配；主角住宅单列。
- `住宅区调整示意.svg`在原A区75 × 62.5 m、C区53.75 × 62.5 m范围内给出地块安排，五栋公寓采用三种模型实例。矩形地块已检查不越界、不互相重叠；树冠可超出种植地块边线。

原总图“庭院每栋4户、河畔3栋两层、主角一层”的设想被本轮住宅方案修订。旧总图文件仍作为历史版本保留；新示意是住宅区落位建议，不代表完整路网、入口朝向或日照审查已经完成。本包提供5种建筑模型，6栋庭院及5栋公寓的最终世界实例由后续总图装配完成。

## Blender编辑

直接打开对应.blend；场景选择包含`01 Exterior`以及每层的`Floor N Interior`和`Floor N Plan`。共5个别墅场景、7/9/11个公寓场景。GLB可通过glTF导入菜单载入其他工程。

本轮接缝修订：别墅楼板与上下层墙体按同一标高衔接，四周设连续楼板边带；阳台与主楼板同高并沿边相接，檐口采用连续盖板及实体山墙。公寓同步修正楼板周边、阳台和屋顶连接。

集合按`L01_Floor`、`L01_Back`、`L01_Front`、`L01_East`、`L01_Interior`、`L01_Stairs`等分层命名；`Roof`为屋顶、`Landscape`为花园、`Studio`为灯光背景。剖切隐藏选定层前侧/东侧外墙和更高楼层，保留下层作为体量参照。Studio仅在Blender工程中，未导出GLB。

单位为米。Blender Z向上、正面-Y；GLB Y向上、正面+Z。中文标牌已转为网格，成品不依赖外部字体或贴图。

## 可重复构建

```sh
blender --background --python src/build_models.py
blender --background --python src/verify_models.py
npm install
npm run preview:build
```

Blender 5.2.2 LTS、Three.js 0.180.0、esbuild 0.25.9。脚本从macOS的`/System/Library/Fonts/STHeiti Medium.ttc`创建中文标牌；其他系统重建需替换字体路径。重建会覆盖生成文件，手工改过的工程请先另存。设置`RESIDENTIAL_KEYS=courtyard,hero`可只重建指定模型。`src/housing_plan.py`从本项目角色库更新容量清单和住宅区示意，需要保留项目目录关系。

这是待视觉反馈的静态游戏场景资产，尚未接入角色行走、楼梯动作、游泳、碰撞、寻路或实际入住系统。模型尺寸服务于本轮空间设计，不是施工图。
