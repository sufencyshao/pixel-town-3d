# 小镇动物生活 V6

完成于2026-10-18。20只原有动物已经以3D模型加入完整小镇，能够自主活动、接受阿澈照看，并与合适的同伴友好互动。保留V5的四季、昼夜、天气与秋风落叶。本版是独立设计预览。

## 打开与操作

直接打开[小镇动物生活-离线预览.html](小镇动物生活-离线预览.html)，模型、纹理与程序已嵌入，断网可用。文件约140MB，首次打开需等模型载入。推荐桌面Chrome；390px窄屏布局也已验证，真实手机性能尚未验收。

1. 通过上方区域按钮或下拉菜单选动物，拖动旋转、滚轮缩放；勾选“镜头跟随”可以近看活动。
2. 点击喂食、轻抚、呼唤、抛球、一起散步或同伴互动。阿澈会沿小镇步道走来；跨镇需要时间，1/2/4倍活动速度可调整。
3. 想立即看互动可点击“在这里开始照看”，明确把阿澈切换到当前到访地点，再点互动。动物仍实际接近和行动。
4. “暂停活动”冻结动物与骨骼动画；下面的“小镇时间”有独立暂停键。天气/夜间变化会中断互动并让动物回各自遮蔽点。
5. 近看时自动临时隐藏遮挡动物视线的静态树冠、棚顶等；回完整小镇后恢复。

## 已实现的生活与互动

- 日常：按物种散步/跳步、观察、嗅闻、梳理、吃东西、饮水和休息；能量、饥饿与口渴缓慢变化。
- 人与动物：先接近再呼唤/照看，猫、狗、兔和矮马支持轻抚；狗支持完整抛球—追球—衔回和陪伴散步。鸟实际沿路线飞到食水点，陆龟与豚鼠可呼唤和喂食。
- 动物之间：同类接近、嗅闻、玩耍后分开；两处同院猫犬互嗅后安静相伴；鸟轮流短飞、换枝、栖停。不会安排狗追逐兔、鸟等小动物。
- 环境：11处活动区域配置独立休息位、食水盆与遮棚，鸟有栖杆和鸟舍。雨雪/强天气/夜间归位；自由活动保持身体间距，鸟使用占位预约和飞行等候。
- 互动细节：喂食有落入食盆的食粒，轻抚包含跪姿/俯身与手臂接触校正，抛球包含手持、抛物线和衔回。低棚下的动物先走到棚外，再接受需要人物靠近的互动。

## 开源基础与修改

先检索并核对许可后选用：

- 犬/矮马：Quaternius [Ultimate Animated Animals](https://quaternius.com/packs/ultimateanimatedanimals.html)，CC0。从GitHub固定提交[FreeModels](https://github.com/agentkaerf/FreeModels/tree/db3df04d1e4714298a09510b26fb6de6645138a2)取得ShibaInu、Husky、Horse，保留完整四足骨架和部分原动作，再修改品种体型、花色、耳尾并补动作。
- 猫：**[Cat by J-Toastie](https://poly.pizza/m/DJ9rpAhrh3)**，**[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)**。从GitHub固定提交[mori-together](https://github.com/wehrleymullanag18-design/mori-together/tree/4fc51d4572ee2e8c3605b6cfa342f15c7e1751a2)取得已注明许可的模型，新增5种毛色/体型细节及动作；没有复用其应用代码。
- 鸟、兔、豚鼠与陆龟：本轮原创网格、关节及动作。未找到适合自然动物姿态且授权清楚的底模时，按原身份制作。

完整署名、精确下载地址、固定提交与原文件摘要见[动物来源与许可](animal-library/ATTRIBUTION.md)、[vendor/sources.json](animal-library/vendor/sources.json)。复制分发猫模型须保留J-Toastie署名及CC BY 3.0说明。

阿澈沿用C方向V1.1副本，22条动作；Pet/Feed由原作业跪姿提取稳定姿态并加轻微运动，抛球为本轮补充，轻抚的俯身/手臂接触由运行程序校正。基础人物、动作与鞋子的CC0材料许可在[caretaker-licenses](reference/caretaker-licenses/)。原人物首版未改。

## 文件与继续修改

- [Town-with-animals.blend](Town-with-animals.blend)：完整小镇＋20只动物＋阿澈＋栖息设施；默认“01 Whole town”场景，全部动物/人物动作保留，纹理已打包。
- `animal-library/assets/`：20个独立GLB与20个独立Blender工程。具体目录以[动物库README](animal-library/README.md)为准。
- [模型总览](animal-library/renders/20只动物-总览.jpg)、[动作姿态总览](animal-library/renders/关节动作-16姿态.jpg)、[中文平面图](整镇分区总图.svg)。
- `src/animal-simulation.js`：独立规则、寻路、需要、预约和互动；`src/animal-world.js`：显示、动画、手部校正与界面。
- `reference/navigation.json`：实际小镇三角网格采样的室外路线；`reference/runtime-spawn.json`：原生工程与浏览器共用的初始摆放/设施参数。
- `Town-complete.glb`：保留的静态小镇。页面“静态小镇GLB”下载此文件，动物分别下载；浏览器自主行为未烘焙到整体GLB/Blender时间轴。

修改JS后，在本目录安装package.json固定依赖，执行`npm run build`，再执行`python3 src/package_preview.py`重新生成独立HTML。完整包已携带animal-library，重建不要求其他聊天/源文件夹。`node --test src/animal-simulation.test.js`检查规则，`node src/nav_runtime_audit.mjs`检查真实地图回归；Blender脚本分别构建照看者、导航和原生整镇。

## 验收与范围

[验收报告](验收报告.md)汇总10项规则测试、54项实际本地互动、50项浏览器检查、原生保存重开、模型动作、地面/鸟类避让及离线打开证据。

当前为完整小镇中的可运行动物设计预览，未替换正式Electron应用，未调用人物API或更改存档、API配置、原2D与V5。阿澈只作人物互动示范，全员3D人物仍待逐人设计。导航是0.5m采样图与简化身体避让，尚无全场物理、脚底IK、室内/楼层寻路和动物长期关系记忆；真实手机/Safari和长时运行尚未验收。
