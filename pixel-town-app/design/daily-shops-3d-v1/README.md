# H 区 · 日常商业街 V1

2026-10-15。沿用小镇“温暖自然、步行街、庭院与绿地”的风格，完成 H 区五间新店，并纳入已经制作的咖啡厅。六店的建筑外观、静态室内与共享街道均在同一个工程中。

## 打开与查看

- 双击 `日常商业街-离线预览.html`：模型、贴图及脚本全部内嵌，无需联网。
- Blender 直接打开 `H-daily-shops.blend`。工程含全景、俯视、六店室内和沿街视角共九个场景。场景下拉框可切换；各店按外壳、屋顶、室内与入口分组。
- 需要导入其他工程时，使用 `H-daily-shops.glb`。单位为米；Blender 工程 Z 轴向上、+Y 向北，GLB 为 Y 轴向上、-Z 向北。
- `布局示意.svg` / PNG 是带中文标注的平面布局；`plan.png` 是实际模型俯视。
- 网页支持单店查看、屋顶及前墙剖切、恢复完整外观、自动旋转、GLB 导出和截图。鼠标拖动旋转，滚轮缩放，右键平移。

## 区块落位

保留原 H 区 85 × 55 m 边界和六栋原规划中心。北排从西向东是咖啡厅、烘焙坊、食堂；南排为杂货铺、花店和理发屋，两排入口相向。中央东西步行巷宽 4.5 m，外摆、花灌木、树荫长椅设在店前退让空间。北侧与南侧分别设收货步道，通过侧向支路连通；北口接 E 区大树广场，西接 G 区田园，东接 I 区旅店。

新店入口与后门有坡面衔接；咖啡厅保留原露台，追加后门坡面。为使后门可用，只在 H 区副本中打开后门、将备餐台旋转靠侧墙，并把冰箱及把手向西移动 0.12 m。原咖啡厅文件与冻结副本均保留，可独立回看。

## 文件与复建

`manifest.json` 记录尺寸、坐标、组名、原资产摘要和 GLB 摘要。`reference/` 保存原咖啡厅、导入变换快照与总图数据。`src/build_models.py` 使用 Blender Python 构建；`src/verify_models.py` 重新打开工程并重导入 GLB 验证。`src/make_plan.py` 生成标注平面，`src/package_preview.py` 将模型及打包脚本内嵌到 HTML。Three.js 与 esbuild 依赖版本见 `package-lock.json`，许可证见 `THIRD_PARTY_LICENSES.txt`。

本轮交付为独立静态设计，等待视觉反馈。人物职业映射仅用于安排空间，尚未接入营业、交易、烹饪、花艺、理发、碰撞或运行时寻路，也未改动正式存档。跨区接口和原咖啡厅约 0.065 m 入口地坪高差需在整镇运行接入时统一处理。验收范围与证据见 `验收报告.md`。
