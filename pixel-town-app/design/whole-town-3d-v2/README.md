# 溪畔日常 · 街道细节 V2

在九区整镇 V1 基础上补齐公共空间设施，保留原建筑、室内、住宅与河流。V1 文件和压缩包独立保留。

## 打开

- `完整小镇-离线预览.html`：双击离线浏览，全镇缩放、九区聚焦、单区隔离及楼层剖切。
- 三个「街道细节」按钮直接查看过街路口、河岸座椅和到达街角；可分别隐藏街道设施与架空电线。
- `Town-complete.blend`：可直接在 Blender 中编辑，按 A–I、T 组织；共七个全景与街景摄影场景。
- `Town-complete.glb`：可导入 Blender 或后续引擎。单位为米；Blender Z 向上、+Y 北；GLB Y 向上、−Z 北。
- `整镇分区总图.png / .svg`：标注总图；SVG 内嵌俯视渲染和矢量标签。

路灯使用发光材质表达暖光，尚未实现昼夜开关与实际夜景照明系统。红绿灯是静态场景道具，不包含信号时序、车辆礼让或道路交通仿真。架空线是美术模型，未进行真实供电系统设计。

## 文件与重建

- `src/build_town.py`：从相邻的原八组区块资产重建整镇，调用 `src/street_details.py` 添加本版细节。
- `src/street_details.py`：设施参数、摆位与新增模型代码。
- `src/verify_town.py`：原资产摘要、网格回读、公共路网抽样检查。
- `src/verify_details.py`：V1 保护、设施数量、电线垂度与柱体/座椅对原几何的净空抽样。
- `manifest.json`：整镇数据、原资产来源与 `streetDetails` 设施位置清单。
- `reference/`：原分区清单、总图与 V1 文件摘要。

使用 Blender 5.2.2 LTS 制作；重建需要相邻的原始分区 `.blend` 文件，已合成的本包模型则可独立打开。预览使用 Three.js 0.180.0；第三方许可证在 `THIRD_PARTY_LICENSES.txt`。

```sh
blender -b --python src/build_town.py
npm install
npm run preview:build
blender -b --python src/verify_town.py
blender -b --python src/verify_details.py
```

当前仍为静态设计资产，没有更改正在运行的应用、人物、API、配置与存档。GLB 保留全部室内，约 85 MiB，离线 HTML 约 115 MiB；运行接入时仍需按区加载与优化。
