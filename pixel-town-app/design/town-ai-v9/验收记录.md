# V9 API 与三维角色操作验收

日期：2026-10-19。用户要求 API/AI 了解项目背景、人物背景特征、职业与关系，并实际使用骨架、原动作和工作流程。

## 已完成

- 新增桌面三维入口与限定窗口 IPC，复用当前 `llm.js` 的 OpenAI 兼容 / Anthropic 接入；真实服务商配置仍由原设置页面管理，密钥不进入三维页面。
- 当前居民实例映射到三维身份；导入姓名、当前人设、背景、兴趣、风格、职业作息、生活方向、私人记忆、单向关系和本人旧日志；全部在场人物的公开档案提供给模型。实际三维时间、天气、距离、可用骨骼、动作和任务随请求更新。
- 严格 JSON 指令协议：原动作、限幅关节姿态、合法步道移动、分阶段职业练习、近距离说话、等待。主进程和渲染器均校验，拒绝未知动作/骨骼/越界角度/替他人工作。
- 44 成人的原动作及 9 个可控关节；40 位职业居民的 3 阶段练习任务；5 陪伴访客不强派职业，儿童不套成人骨架能力，动物不使用人类语言或职业。
- 移动使用已验证室外地面网格、最大高差和其他角色占位；无步态不滑行。到达后真实计时，动作/工作完成、失败、取消、中断分别回传并持久化；原子写入失败可重试且暂停后续 API。
- 台词实际送给附近人物；其回复由其独立模型决定，不编造对方意见，不自动改好感。实际回执进入后续上下文。
- 单次与自主开关、最短自动间隔、每日上限、取消请求、配置变更丢弃过期返回、手动动作/后台停止，以及窗口中断记录。
- 独立 V9 数据目录首次复制原已加密存档与日志；后续不覆盖 V9，不写原始正式存档。实际启动已确认继承45人物、3服务商、6个非演示绑定，自主调用为关闭状态；未发真实付费请求。

## 准确边界

真实第三方付费 API 未代用户调用；测试采用本地服务商，付费调用 **0**。支持现有 API 协议不等于本轮已验证每一家服务商的账户连通性。

工作是室外工作点的职业练习和持久记录，不是完整生产/交易系统。没有实物生产、库存、货币、真实诊疗、工具抓取/IK、设备操作、室内/上楼、驾驶、全动作碰撞或衣物物理；动物自主位移、食水、追球未接。缺失6个动物的原档案保留。本轮运行逻辑不烘焙进原静态 `.blend` / GLB，未覆盖或重装正式 `/Applications/像素小镇.app`。
