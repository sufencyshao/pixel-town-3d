## 打开查看

- `完整小镇-离线预览.html`：双击即可离线查看，全部模型与脚本内嵌。约 109 MiB，首次打开需要解码模型。拖动旋转、滚轮缩放、右键平移。

- `Town-complete.glb`：Blender → 文件 → 导入 → glTF 2.0，或用于后续游戏引擎。
- `整镇分区总图.png` / `.svg`：中文标注总图，北向上。SVG 内嵌俯视渲染，区块标签是矢量文字。
- `overview.png`、`plan.png`、`riverside-town.png`、`town-centre.png`：四张渲染。

按实际地图阅读：北排 A / B / C，中排 D / E / F，南排 G / H / I。整镇场地 300 × 225 m。保留原区块建筑尺寸、朝向、家具与绿化，住宅共 46 户居民 + 主角 1 户，另有 6 间旅店客房。

原 A/C 场景的 B 区占位与重复道路背景已经移除，改放实际 B 区。F 区的独立截面封边在合并副本中移除；河流与两岸步道延伸至全镇南北边界，两座跨河桥保留。38 处区块公共接口经连接步道和短过渡坡接入主路。桥面与河岸步道交会处增加 8 段短坡。

交通组织沿西、南、北侧安排外围联系，I 区车场接南侧道路；东侧作为河岸慢行空间。当前是静态场景，未实现车辆运动或交通系统。

## 编辑与剖切

Blender 按 A–I 九个集合与 T 公共环境集合组织。为减少整镇对象数，区块内按建筑、楼层和部件合并成 465 个网格。顶棚、外墙、室内与楼层仍有独立部件；细节可进编辑模式编辑，若要逐家具对象编辑可回到各区原工程。Studio 集合只服务渲染。

浏览器支持九区聚焦、单区隔离、屋顶开关、俯视和剖切；A/B/I 可切换二层，C 可切到五层。切层为查看室内的展示控制，不是人物行走或楼梯系统。E 区可开关市集与中央树冠。

Blender 使用米、Z 向上、+Y 为北；GLB 使用 Y 向上、−Z 为北。全局原点对应原平面图坐标 (620,540)，图面 4 单位折合 1 m。

## 来源与重建

本包模型可独立打开。`reference/` 冻结原总图和区块清单，`manifest.json` 记录每个原模型摘要、坐标和合并调整，原始八组文件均未覆盖。

`src/build_town.py` 需在原项目 design 目录下运行，并依赖相邻八组区块 `.blend`；它们未重复纳入此包。`src/model_helpers.py` 已冻结。

```sh
blender -b --python src/build_town.py
npm install
npm run preview:build
blender -b --python src/verify_town.py
```

`TOWN_SKIP_RENDERS=1` 可跳过重渲染。浏览器基于 Three.js 0.180.0；许可证见 `THIRD_PARTY_LICENSES.txt`。

当前完整保留各区静态室内及庭院。人物入住、营业活动、宠物行为、碰撞体、寻路网格、门和车辆动画以及正式应用存档仍待后续接入。
