# H01 溪畔咖啡厅 · 3D 模型 V1

2026-10-12。用户在总图 V1 后明确要求先制作咖啡厅；本轮据此推进单栋模型，不视为整张总图已最终签收。

## 查看与使用

- 双击 `咖啡厅-离线预览.html`：单文件离线 3D 查看器，不需要联网或安装 Node。
- `index.html` 与 `cafe.bundle.js`：同一预览的分离文件版。
- `H01-cafe.glb`：真实网格及材质模型，约 1.84 MB；可导入支持 glTF/GLB 的建模或游戏工具。含店招贴图，不依赖远程纹理。
- `exterior.png`、`interior.png`、`top.png`、`counter.png`、`evening.png`：从实际 WebGL 模型渲染导出的图像，不是生成式概念图片。
- `src/scene.js`：可编辑的参数化建模与查看器源码。
- `model-manifest.json`：尺寸、空间坐标、工作点和后续接入约定。
- `validation.json`、`review.md`：本轮检查证据与边界。

预览支持拖动旋转、滚轮／双指缩放、右键平移，提供完整外观、室内剖切、俯视布局和吧台近景四种视角，可切换屋顶、傍晚灯光和自动旋转，并下载 GLB 或保存当前图像。GLB 下载总是导出完整建筑，不受当前剖切状态影响。

## 建筑与空间

H01 原总图矩形约 23.5 × 13 m。本轮将它作为咖啡厅预留用地，建筑主体缩进为 18 × 9 m（162 m²），南侧安排临街露台与轻木格架，主体主要一层，屋脊约 5.9 m 高。含露台、花箱的导出模型最大包围尺寸约 22.7 × 12.04 m，仍在原预留尺度内；预览的两棵树、展示底板与背景地面为场景布置，未导入建筑 GLB。

采用浅色抹灰、橡木、鼠尾草绿门窗与陶土色坡屋面。坡屋面用简单板缝表达，并非逐片瓦片。门面有落地玻璃、主入口、店招、露台双人桌及花箱。

- 室内 18 座：4 张双人桌（8 座）、共用长桌（6 座）、靠窗吧座（4 座）。
- 露台 4 座：2 张双人桌。
- 工作区：L 形吧台、三头咖啡机、磨豆机、甜品柜、收银台、后侧水槽及储物展示架。
- 后勤区：备餐储物间、冰箱、独立卫生间、背面后勤入口。
- 吧台后侧净深约 1.7 m；吧台东端与服务房间之间约 1.25 m。其余座位间距仍应结合角色碰撞半径和椅子拉出范围在游戏灰盒中校准。

职业对应原默认目录的林屿、沈知、闻豆；尚未给现有存档中的人物绑定岗位。

## 坐标与分组

单位为米，Y 向上，+Z 朝正门与街道，+X 朝建筑东侧。原点位于建筑平面中心附近，室内完成地面 y≈0.155；建筑西东外墙 x≈±9，南北外墙 z≈±4.5。地面高度、人物脚底锚点与全镇标高尚需在实际接入时统一。

GLB 根节点 `H01_Creekside_Cafe`：

- `Architecture`：地基、墙体、门窗；含 `FrontFacade`、`EastFacade`、`RemovableRoof`。
- `Interior`：地板、家具；含 `CoffeeBar`、`ServiceRooms`、`PendantFixtures`。
- `Terrace`：露台、座椅、格架与店招。
- `Landscape`：建筑附属花箱。

剖切预览通过隐藏整个屋顶、前立面和东立面观察室内，模型结构本身仍保留。当前只有静态几何，没有门扇动画、人物动画、碰撞体、导航网格、交互脚本或经济生产逻辑。模型导出不带预览相机、太阳／环境光与背景场景；导入后需要在目标软件中设置灯光。

## 继续编辑

本次使用固定版本 Three.js 0.180.0 与 esbuild 0.25.9。已交付构建后的查看器，直接查看无需安装依赖。若需修改源码，可在此目录执行 `npm install`，然后 `npm run build`；离线单文件版需重新把构建脚本内嵌到 HTML，避免与源码版本不一致。依赖许可见 `vendor/THREE-LICENSE.txt`。

GLB 已用同版本 GLTFLoader 重新载入，确认 790 个网格，约 2.77 万三角面。已在本机 Blender 5.2.2 LTS 完成导入、两视角 Cycles 渲染与保存后重开检查，详情见 `blender-validation/验收报告.md`；最终游戏引擎尚未验收。细小器具保留为独立网格，适合继续编辑；全镇同时加载多栋前需要做实例化、材质合并与 LOD。

本轮未修改应用运行源码、正式人物素材、存档、API 配置或安装包。用户视觉反馈后可继续调整造型、屋顶比例、家具风格和内部布局。
