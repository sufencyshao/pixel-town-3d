# I 区 · 到达与守护 V1

2026-10-14。沿用溪畔小镇温暖自然、低多边形的建筑风格，制作公交候车、双层旅店和消防值守场景。

## 查看与编辑

- `到达与守护-离线预览.html`：模型和Three.js资源内嵌，双击即可离线查看。支持区域全景、总平面、旅店外观、一层接待、二层客房、消防站内部、公交候车七个视角，以及屋顶开关、旋转缩放、截图与GLB下载。
- `I-arrival-guard.blend`：原生Blender工程，含七个已保存取景场景。
- `I-arrival-guard.glb`：完整可交换模型，按楼层、立面、家具、道路和车辆分组，无外部贴图依赖。
- `布局示意.svg`：中文标注平面图。
- `overview.png`、`plan.png`、`inn-exterior.png`、`inn-lobby.png`、`inn-rooms.png`、`fire-interior.png`、`bus-stop.png`：实际Blender渲染。
- `manifest.json`、`validation.json`、`qa/browser-checks.json`、`验收报告.md`：尺寸、房间、通路与本轮检查证据。

## 原总图与位置

依据 `../town-3d-masterplan-v1/plan-data.json` 的I区，215 × 220图纸单位按4单位/米换算为53.75 × 55 m。片区中心为原图(932.5,830)，模型坐标：`x=(planX-932.5)/4`、`y=(830-planY)/4`；Blender北为+Y，Z向上；GLB北为-Z，Y向上。

## 场景配置

旅店一层有接待台、钥匙架、两组四人早餐桌、休息沙发、书桌和独立备餐间；西北侧20级双跑楼梯通过实际楼板开口到达二层。201—206六间客房分别配置双人床、书桌、衣柜与独立卫浴。二层走廊宽2.4 m；北侧有木廊休息露台。

消防站设东向两个车库位，门洞宽4.65 m，卷帘呈开启状态。一辆静态消防车停在南车位，北车位留空；西侧为值守与休息空间，北侧设四组装备柜及头盔，车库内有水带和整备台。门口缓坡衔接地坪与前场。消防前场不放置候车座椅或绿化。

公交站有遮雨棚、长椅、站牌、触觉提示铺装与一辆小巴。小巴靠西侧平台停靠，东侧留通行空间。公交停靠与消防前场沿南北方向分离；步行路从候车区进入旅店及西侧商业街，并向北接河岸公园。

## 重建

```sh
blender --background --python-exit-code 1 --python src/build_models.py
blender --background --python-exit-code 1 --python src/verify_models.py
npm ci
npm run preview:build
python3 src/make_plan.py
```

使用Blender 5.2.2 LTS、Three.js 0.180.0、esbuild 0.25.9。`I_SKIP_RENDERS=1`可跳过渲染。冻结的模型基础函数在 `src/model_helpers.py`；中文网格标牌构建时使用macOS STHeiti字体。重建会覆盖生成资产，人工编辑应先另存。

本轮为独立静态设计。车辆、入住、公交班次、消防事件、人物工作、碰撞与寻路未接入运行应用；各尺寸用于场景设计，不作为施工图或规范验收结论。原有住宅、F/G区资产及正式存档不在本轮编辑范围内。
