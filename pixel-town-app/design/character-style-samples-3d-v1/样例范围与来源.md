# 人物 3D 比例样例 V1

2026-10-17。用户要求先看每种类型的简单例子再决定；本轮制作三种比例，暂不批量转换40位居民，也不替换现有2D应用。

三者统一参考阿澈（01_hero_male）的黑短发、棕眼、黑色上衣和蓝裤，保持相同展示高度与动作：A 大头Q版、B 稍修长卡通、C 偏写实比例。C 使用较接近成年人的比例，仍是风格化底模，未制作照片级皮肤。提供可旋转、可切换站立/走路/挥手的离线预览以及可编辑模型。

## 已检查的基础

| 基础 | 已查到的内容 | 本轮处理 |
|---|---|---|
| Quaternius Universal Base Characters + Universal Animation Library | 人形骨骼、动画友好拓扑、配套动作；官方页面和下载内许可证为CC0 | 用作三个例子的共同模型/骨骼和基础动作来源，按原2D人物改配色、发型与比例 |
| NafisRayan/Animate-Rigged-Humanoid-No-Blender | GitHub仓库保存上述Standard资产及合并示例 | 从固定提交读取需要的资产；不把README声称的全部动作数量直接作为验收结论，不使用未声明许可的合并代码 |
| rana-jatin/avatar-stage | MIT；骨骼识别、15个程序动作、表情接口；演示模型没有ARKit表情形变 | 作为后续动作驱动候选；本轮不额外引入其整套运行框架 |
| ChilyerStudiosLLC/blender-character-pipeline | 服装与共享骨骼工作流示例，作者明确说明并非完整人物资产包 | 作为后续服装定制参考；不当作现成人物全集 |

以上属于针对小镇需求的初筛，不声称是GitHub所有人物项目的全量排名。样例通过后，再按选定方向核对完整动作、表情、手指、衣物和全员身份细节。
