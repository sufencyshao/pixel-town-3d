# B 区 · 公共服务庭院 V1

完成 B01–B06 六栋建筑的区块装配：本次新增小学、社区中心、邮局与警务站；纳入已有的两层平顶图书馆和带医疗红十字的平顶诊所。六栋均含静态室内，保留温暖自然的木色、奶油墙面和绿化风格。

## 查看与编辑

直接打开 `公共服务区-离线预览.html`：模型和查看器均已内嵌，无须联网。提供整区、平面、六栋室内及公共庭院共九种视角，支持屋顶显隐、单栋隔离、图书馆一/二层切换、GLB 下载与截图。Blender 工程和标注平面链接需要同目录文件。

在 Blender 打开 `B-public-services.blend`。已保存九个审阅场景：整区、首层总平面、六栋室内、图书馆二层。集合以 B01–B06 为前缀，墙体、屋顶、室内及入口分组，图书馆二层另有 `B02_Upper*` 集合；`Studio` 仅包含摄影背景、相机与灯光，不导出到 GLB。GLB 也可直接导入 Blender 或后续游戏引擎。

`布局示意.svg` / PNG 为带中文标签的简化平面；`overview.png`、`plan.png`、`B01-interior.png` 至 `B06-interior.png`、`B02-upper.png` 为实际 Blender 渲染。

## 区块与步道

地块沿用总图 B 区 **85 × 62.5 m**。北排为小学、图书馆、诊所，南排为社区中心、邮局、警务站。4 m 宽中央步道贯通东西；南入口接大树广场方向，经邮局后侧步道与两条南北支路进入庭院；东、西边界分别面向河畔住宅、庭院住宅。北侧为连续花园步道。

小学主体较原预留中心向北调整 1.75 m，给门前操场和绕行步道留空间；其他五栋中心沿用总图。新建筑尺寸在原预留地块内细化，原图书馆、诊所维持原尺寸。静态花灌木、长椅、阅读廊架和诊所等候小庭均已落位。

模型单位为米，Blender Z 轴向上、北为 +Y；GLB Y 轴向上、北为 -Z。本区坐标原点对应旧总图绘图坐标 (620, 245)，4 个绘图单位为 1 m。与其他分区的最终道路高程、边界衔接仍待整镇装配统一。

## 已有建筑的保护

原 `civic-buildings-3d-v2` 目录及原有 .blend / GLB 保持不变，源文件摘要记录于 `manifest.json`。本包 `reference/civic-buildings-3d-v2/` 保留其快照，便于离线重建。

区块副本仅对以下内容做适配：两个入口坡道改为连接公共铺装 z=0.09 m 与原门廊 z=0.14 m；诊所东侧墙基和玻璃分段形成约 1.34 m 净宽辅助门，补门框、雨棚和坡道。原门廊到室内地面的约 0.05 m 小高差仍保留，后续碰撞/角色行走接入时统一处理。该模型是游戏场景设计，不是施工图。

## 重建

Blender 5.2.2 LTS；查看器 Three.js 0.180.0、esbuild 0.25.9，开源许可在 `THIRD_PARTY_LICENSES.txt`。

```sh
blender --background --python src/build_models.py
blender --background --python src/verify_models.py
python3 src/make_plan.py
npm install
npm run preview:build
```

生成脚本优先读取包内冻结的两个已有建筑。中文标牌已转网格，打开模型无需字体；重建标牌使用 macOS `/System/Library/Fonts/STHeiti Medium.ttc`，其他系统需替换字体路径。重建会覆盖本目录输出，手工修改的工程应先另存。

本轮为可编辑的独立静态区块；人物上学、看病、办事、邮递、碰撞、寻路、门的动画与楼梯行走尚未接入。当前待用户视觉反馈。
