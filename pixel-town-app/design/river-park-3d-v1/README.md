# F 区 · 河岸公园 V1

2026-10-13。按“完成F：河岸公园区域”制作，沿用现有米白、鼠尾草绿、原木和低多边形绿化风格。独立场景设计，等待视觉反馈。

## 打开与编辑

`河岸公园-离线预览.html`内嵌GLB及Three.js，无需联网，可切换公园全景、分区总平面、兽医小屋内部、宠物草地、林间舞台、河岸观景、安静栖息角七个视角；支持屋顶开关、自动旋转、GLB下载与保存PNG。

`F-river-park.blend`为原生工程，含六个已保存场景。`F-river-park.glb`为可交换模型；两者均按建筑、设备、植物、步道和河岸分组。中文标牌已转换成网格，无外部字体或贴图依赖。HTML中的Blender/SVG链接需保留目录结构。

附六张实际Blender渲染、带标注的`布局示意.svg`、`manifest.json`、`validation.json`和`验收报告.md`。

## 规划关系

公园核心沿用原总图F区215 × 220图纸单位，换算为53.75 × 55 m。地块中心对应总图(932.5,540)，Blender坐标`x=(planX-932.5)/4`，`y=(540-planY)/4`，Z向上。GLB为Y向上、北为-Z。

兽医小屋F01保持原占地23 × 13 m，中心(-10.875,11)，南门朝主步道。西通中央广场，北接河畔住宅，南接到达区。

为展示“河岸”完整关系，本模型包含核心地块以东的河流、对岸自然步道和南北两座桥。桥中心纵坐标35和-36.25 m沿用原图400/685两条桥线，桥面4.75 m宽；河宽约20 m。展示包络约98.875 × 80 m，**不表示把F区核心扩大到该尺寸**。岸线采用适合本次模型的平滑曲线，是相邻环境设计示意；整镇装配时仍需统一校准河道、外环道路及相邻区块边界，未改写旧总图。

## 功能空间

- 兽医小屋：候诊座椅、接待台、检查台、护理工作位、恢复休息格、清洗和储物。实际门洞连接各区，室内预览可隐藏屋顶和前/东外墙。
- 宠物草地：19 × 19 m围栏草地，双门缓冲入口、钻洞、低栏、踏木、饮水碗、长椅与遮阴树，保留中央活动空地。门以打开姿态展示，尚无门的交互逻辑。
- 林间小舞台：10 × 6 m木台、弧形遮顶、背板、音箱和话筒架；台前六张长椅，建议约18个坐席。三级台阶和侧边缓坡均为实际几何。
- 河岸：弯曲慢行道、北桥和南桥、临水观景木平台、长椅、护栏、芦苇与岸石。桥栏在过水段设置，为陆侧步道交叉留开口。
- 自然栖息角：与宠物草地分开布置，含浅水点、晒背木、鸟屋、树木和灌木隐蔽空间；不把自然动物混入宠物活动围栏。
- 公共设施：饮水点、分类桶、低位公园灯、方向标牌和自然花境。

角色沿用原方案：安安对应兽医和动物照护，迟野可在户外音乐区活动。本轮未绑定角色行为，也未摆放人物或动物模型。

## 重建

```sh
blender --background --python src/build_models.py
blender --background --python src/verify_models.py
npm ci
npm run preview:build
python3 src/make_plan.py
```

Blender 5.2.2 LTS、Three.js 0.180.0、esbuild 0.25.9。`src/model_helpers.py`为从既有建筑冻结的建模函数。构建中文标牌需macOS字体`/System/Library/Fonts/STHeiti Medium.ttc`；其他平台重建请改字体路径。`F_SKIP_RENDERS=1`只跳过PNG渲染，仍会重建工程和GLB。人工修改工程前请另存，脚本重建会覆盖生成资产。

本次为静态游戏场景；尚未接入人物/宠物行为、门、碰撞、寻路、医疗功能、演出逻辑或水流动画，也不代表正式游戏已迁移到3D。尺寸和检查服务于场景设计，不是施工图或建筑规范审查。
