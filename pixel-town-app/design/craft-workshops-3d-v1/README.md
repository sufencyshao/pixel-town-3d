# D 区 · 手作工作区 V1

2026-10-14。温暖自然的低多边形小镇场景，包含四栋单层工作场所、展示小巷、后勤路、休憩长椅、灯具、雕塑及混合花灌木。当前为独立可编辑设计资产，待视觉反馈。

## 查看和编辑

- `手作工作区-离线预览.html`：模型与 Three.js 已内嵌，可直接双击离线查看。包含全景、总平面、四栋室内和展示小巷七种视角。支持屋顶开关、仅显示当前建筑、旋转缩放、GLB 下载和 PNG 截图。
- `D-craft-workshops.blend`：在 Blender 中直接打开。场景下拉菜单提供七个视角；室内场景自动隐藏对应屋顶与入口立面。
- `D-craft-workshops.glb`：可导入 Blender 或其他支持 glTF 的编辑器。集合父节点保留，材质无外部贴图依赖。
- `布局示意.svg`：带中文标注的总平面；`overview.png`、`plan.png`、`wood-interior.png`、`repair-interior.png`、`art-interior.png`、`music-interior.png`、`makers-lane.png` 为 Blender 实际渲染。

离线 HTML 的 Blender/SVG 下载链接需要保留同目录文件。GLB 内嵌下载不需要其他文件。

## 功能和尺度

| 建筑 | 外墙轴线占地 | 内部内容 | 原方案工作角色 |
| --- | --- | --- | --- |
| D01 木工坊 | 27.5 × 15 m | 四张木工台、台钳与夹具、木材架、车床、工具墙、除尘设备及成品展示 | 大森、榆棠 |
| D02 修理铺 | 30 × 15 m | 接件柜台、两张电子维修台、两处自行车维修位、工具车、零件收纳 | 罗栓 |
| D03 共享画室 | 27.5 × 13.25 m | 六组画架、两张共用画桌、颜料架、洗笔池与作品墙 | 鹿眠 |
| D04 排练室 | 30 × 13.25 m | 入口缓冲区、休息座位、钢琴、合奏台、鼓组、两把吉他、音箱与麦克风 | 迟野 |

全部地块为 75 × 55 m。建筑中心、占地和主门方向沿用 `town-3d-masterplan-v1/plan-data.json` 的 D01–D04。木工坊及修理铺主门朝南，画室与排练室主门朝北，共同面对中间的小巷。北侧两栋为坡屋顶，南侧两栋为平屋顶；画室有带真实楼板开口的采光天窗。墙体从 Z=0.18 到 4.18 m，屋顶和墙体连续衔接。

中央展示步行带宽 4 m，南北步行脊线宽 3 m；西侧服务路宽 4.3 m、北侧后勤路宽 4.5 m。西侧木工后门和北侧维修收货门连接后勤路线；长椅与树木位于步行带以外的小口袋空间。北侧后勤路与南北步行脊线有交会，整镇装配时统一处理路口。局部入口铺装至室内地坪约有 0.10 m 高差，未作为无障碍工程设计。

地块中心是 Blender 原点，Z 向上、北为 +Y。旧总图换算：`x=(图纸X-270)/4`、`y=(540-图纸Y)/4`。GLB 为 Y 向上，北为 -Z。场景边缘接口为预留位置，未装配到整镇运行世界。

## 组织与重建

每栋按 `D01_Floor / Shell / Front / Roof / Interior` 等独立命名，场地按 `Ground / Paths / Landscape / Street_Furniture / Logistics / Wayfinding` 分组。建筑和家具均为真实网格，文字已转网格。

```sh
blender --background --python src/build_models.py
blender --background --python src/verify_models.py
npm ci
npm run preview:build
python3 src/make_plan.py
```

建模及验证使用 Blender 5.2.2 LTS；预览使用 Three.js 0.180.0、esbuild 0.25.9，依赖版本和许可随包提供。`model_helpers.py` 是本区冻结的基础函数，不修改或依赖其他区块的建模脚本。构建中文字使用 macOS 的 `STHeiti Medium.ttc`；跨平台重建需替换字体路径。重建会覆盖生成资产，人工编辑请先另存。

验证脚本在项目中会对照相邻的旧总图数据。解压独立包时附带 `reference/masterplan-D.json` 快照，可独立执行验证。
