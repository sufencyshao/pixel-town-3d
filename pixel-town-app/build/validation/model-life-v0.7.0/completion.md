# 像素小镇 v0.7.0：自主生活、基础资料与每日日志

2026-10-04。已完成实现并安装到 `/Applications/像素小镇.app`；正式启动正在等待 macOS 钥匙串授权，尚未完成真实服务商的自主运行观察。授权窗口必须由用户操作。没有手动发起人物行为或聊天请求。

## 已实现

- 每次 API 调用携带实际应用功能、可执行动作、公共区域、游戏时段、个人需求、选定人设、生活方向、持续目标与近期自身经历。45 位目录人物按职业和兴趣分别初始化日常参考，世界资料和个人方向可编辑；可免费查看本次基础上下文。
- 自主生活开启后持续轮流决策，模型自行决定目的、动作、目的地、活动时长、邀请与目标延续。低精力、社交需求或天色变化可触发对长行为的重新考虑；行走中等待到达。正常退出重启后保留自治选择，旧档未开启时保持默认关闭。
- 到达相遇区后开展自主交流，复用模型生成的邀请开场白；双方分别选择继续、拒绝、表达不同意见或结束。一段最多六轮，各人独立评价感受，好感变化可以不同，继续请求仍受每日额度限制。
- 为全部人物、动物、小镇、四个公共区域、太阳/月亮及存在的玩家主角分别建立按游戏日保存的日志。区分计划、开始、到达、结束、心声、台词、听到的回应、近处目击与环境；动物记录自然行为与感官刺激。支持日期/类别筛选、分页与整天 Markdown 导出。
- 日志独立于场景最近 180 条手记，磁盘历史保留；每次调用只携带自身最近三个有记录日期中最多 12 条近期记录。目前没有完整历史语义检索。日志、查看资料与编辑本身不额外调用模型。

## 正式配置与启动

保留最新正式存档中的六位 DeepSeek 测试居民：小满、林屿、阿禾、知秋、鹿眠、夏芽，模型均为 `deepseek-v4-flash`。其他人物未扩大 API 绑定。保留人物档案、外观、入住状态、服务商、密钥密文、历史记录与既有每人参数；沿用 60 秒自动间隔和每日 100 次逻辑调用上限。

按用户要求将正式存档的 `autonomous`、`resumeAutonomy` 与 `running` 设为 true，其他存档字段保持原值。启动进程确认来自正式安装路径；进程采样表明启动正等待 `SecKeychainFindGenericPassword` 的系统授权。此时游戏时钟未推进、尚无新增 API 统计或正式日志，不能据此声称真实自主生活已经跑通。用户完成系统授权后还需观察自动调用与日志落盘；请求仍受现有间隔和每日额度约束。

工作、运动与交流使用已有动画和公共区域；当前没有实体建筑、职业产出、物品库存、经济或完整心理模拟。模型目标“完成”属于自评，实际动作到达/结束另有执行日志。
